Desafio de modelagem de uma base de dados de e-commerce utilizando o Power BI. Esse desafio faz parte do Bootcamp da DIO "Primeiros Passos em Power BI''.

Etapas realizadas para a modelagem:
  •	Criação das tabelas dimensão a partir de cópias da tabela fato (tabela Financial Sample);
  •	Utilização da função de “Agrupar por” para a criação de colunas desejadas
  •	Criação de índices a partir de uma coluna condicional
  •	Análise das tabelas para exclusão de colunas desnecessárias e ordenamento
  •	Criação de relacionamentos
  •	Criação da tabela “Calendar” com o uso das funções DAX (CALENDARAUTO, WEEK, FORMAT)
  •	Criação do relacionamento da tabela “Calendar” com a tabela F_Vendas.
